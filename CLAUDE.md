# CLAUDE.md — worldsim-scene-master

Правила для Claude Code в этом репо.

## Что это

Рендерер сцен. Одна функция: `run(input, *, client, model) -> str`.

## Границы

- Ничего не пишет в канон. Output — строка для терминала.
- Не придумывает факты, NPC, локации. Только раскрашивает то, что
  прислал оркестратор.
- Уважает epistemic filter: `player_knowledge` — единственный источник
  того, что можно произнести как "игрок знает/замечает".

## Изменение поведения

- 90% случаев — правка `prompts/render.md`. Код — две страницы клея.
- Тон/длина/стилистика — там же, в промпте.

## Тесты

`python -m pytest -q`. Без API-ключа — только smoke-тест.
